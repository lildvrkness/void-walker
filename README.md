# VOID WALKER

A short-form, browser-based dark fantasy action RPG built with HTML Canvas, CSS, Python, and JavaScript. It is designed as one complete run from the first breach to the final guardian.

## Runs locally

Open `index.html` in a modern browser, or serve this folder with any static HTTP server. No build step or external dependency is required.

## Controls

- WASD/arrow keys: move
- Mouse: aim (desktop)
- Space/J: attack
- Shift/Q/E: Dash
- I: open or close inventory; Escape closes it
- 1–4: switch to an unlocked weapon
- R or the RESTART button: restart the run
- Touch screens: use the on-screen directional pad, ATTACK, and BAG controls

## The journey

1. Explore the Crackled Void and its connected Underground Oasis and Abandoned Factory.
2. Defeat the Amphibian Warden and the Nail-Witch to open the northern gate.
3. Find the rare Void Spiral in one of the three lower regions to empower every weapon.
4. Enter the Void Sanctum and defeat the multi-phase Void Demon.

## Gameplay systems

- Real-time combat with four distinct weapons: sword, knife, mace, and ranged staff
- Weapon-specific attack animations and effects
- Breakable void crates with randomized weapon and vitality rewards
- Random enemy drops, guardian armor, and stacking damage reduction
- Three guardians with telegraphed special attacks and escalating phases
- Health, void resonance, inventory, boss health, and restart interfaces
- Keyboard, mouse-aim, and touchscreen controls

## Run format

This is a single-session playthrough. High Score and Best score is locally stored and reset on exit. There is no persistent save system: death ends the run, and players can restart at any time.

## Assets

All artwork in `assets/sprites/` was cropped from the existing approved concept atlases. The reference atlases are retained in `assets/reference_atlases/`. No additional artwork is needed to run the project.
